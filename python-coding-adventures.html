🔮 Spells and instructions

Computers are great at math, but they're totally literal: they need step-by-step instructions. A list of instructions is called code, and a whole list of it is a program.

🛠️ How it works

  • print() is a built-in command that shows whatever is inside the parentheses ( ).
  • The quotation marks " " tell Python the text inside is a string: a chain of letters and symbols.

Chapter 3

Making Choices & the Magic 8-Ball 🔮

🛣️ How computers decide: if, elif, else

Life is full of choices: if it's raining take an umbrella, else wear sunglasses! Python decides the same way.

score = 95

if score >= 90:
    print("🌟 Super Star! You earned a Golden Trophy!")
elif score >= 50:
    print("👍 Good job! You passed the level!")
else:
    print("💪 Keep practicing! Try again!")

⚠️ The 4 spaces before each print matter! That indent tells Python which lines belong to the choice.

🎲 Lists and random picks

A list holds many items inside square brackets [ ]. Python's random module can pick one for you!

import random
colors = ["Red", "Electric Blue", "Neon Green", "Purple"]
chosen_color = random.choice(colors)
print("Your lucky color today is: " + chosen_color)

Chapter 4

Repeating Magic: Loops & Rocket Blastoffs 🚀

🔄 Why do we need loops?

Want to print "Hello!" 100 times? Typing it 100 times would be super boring. A loop repeats code for you!

1️⃣ The for loop: counting with range()

Use for when you know how many times.

for number in range(1, 6):
    print("Iteration count:", number)
Iteration count: 1
Iteration count: 2
Iteration count: 3
Iteration count: 4
Iteration count: 5

📌 range(1, 6) starts at 1 and stops before 6.

🎮 Project 1: Rocket Countdown Timer!

import time

print("🚀 Prepare for Rocket Launch! 🚀\n")

for count in range(5, 0, -1):   # 5, 4, 3, 2, 1
    print(f"T-minus {count}...")
    time.sleep(1)               # wait 1 second

print("🔥 BLASTOFF! 🌌")

2️⃣ The while loop: repeat until something changes

energy = 3
while energy > 0:
    print(f"⚡ Energy remaining: {energy}")
    energy = energy - 1
print("😴 Out of energy! Time to sleep.")
⚠️ Watch out! If energy never went down, the loop would never stop. That's an infinite loop! (Press the Stop button, or Ctrl+C, to escape.)

🎮 Project 2: The Secret Dragon Code Breaker!

Guess the dragon's vault code before you run out of attempts!

import random

secret_code = random.randint(1, 10)
attempts_left = 3
guessed_correctly = False

print("🐉 THE DRAGON'S VAULT CODE BREAKER 🐉")
print("Guess the secret code number between 1 and 10!\n")

while attempts_left > 0 and not guessed_correctly:
    guess = int(input(f"Enter your guess ({attempts_left} attempts left): "))

    if guess == secret_code:
        print("🎉 BINGO! The vault opens and gold coins pour out! 🪙✨")
        guessed_correctly = True
    elif guess < secret_code:
        print("📈 Too low! The dragon snorts fire!")
        attempts_left -= 1
    else:
        print("📉 Too high! Try a smaller number!")
        attempts_left -= 1

if not guessed_correctly:
    print(f"\n💥 Out of attempts! The secret code was {secret_code}.")

int(...) turns the typed text into a real number so Python can compare it. attempts_left -= 1 is a short way to write attempts_left = attempts_left - 1.

Chapter 5

Drawing with Code: Turtle Graphics 🎨🐢

Turtle is a built-in drawing studio. Imagine a little robot turtle carrying a magic pen: wherever it walks, it draws!

🛠️ Basic turtle moves

CommandWhat it does
turtle.forward(100)Walk forward 100 steps
turtle.left(90)Turn left 90 degrees (a corner!)
turtle.color("purple")Change the pen color
turtle.pensize(5)Make the line thicker

🎨 A rainbow square (loops + turtle!)

import turtle

screen = turtle.Screen()
screen.bgcolor("black")

artist = turtle.Turtle()
artist.shape("turtle")
artist.pensize(3)

colors = ["cyan", "magenta", "yellow", "lime"]

for i in range(4):
    artist.color(colors[i])
    artist.forward(150)
    artist.left(90)

screen.mainloop()
🧠 Why 4 times and 90°? A square has 4 sides and 4 corners. 4 × 90° = 360°, one full spin, and the turtle ends up right back where it started! A triangle needs range(3) and a turn of 120. (360 ÷ 3)

🌌 Master Project: Cosmic Starfield Painter!

import turtle
import random

win = turtle.Screen()
win.bgcolor("#0B0C10")           # deep space black
win.title("🌌 Cosmic Starfield Painter")

pen = turtle.Turtle()
pen.speed(0)                      # fastest!
pen.hideturtle()

star_colors = ["#FF007F", "#00E5FF", "#FFE600",
               "#FF5722", "#00FF66", "#FFFFFF"]

def draw_star(t, size):
    """Draw a 5-pointed star"""
    t.begin_fill()
    for _ in range(5):
        t.forward(size)
        t.right(144)
    t.end_fill()

for star in range(30):
    x = random.randint(-300, 300)
    y = random.randint(-250, 250)
    size = random.randint(10, 40)

    pen.penup()
    pen.goto(x, y)
    pen.pendown()
    pen.color(random.choice(star_colors))
    draw_star(pen, size)

print("✨ Cosmic masterpiece complete!")
win.mainloop()

A def makes your very own function: a spell you name once and cast again and again. penup() lifts the pen so the turtle can move without drawing.
